# Стан проєкту й перевірка

Стан зафіксовано 2026-11-25 на підставі коду та історії роботи з власником.
Назва в serial — `AIRSPEED v6`; останні зміни позиції нижнього статусу
не змінювали цей рядок версії. Він не є унікальним ідентифікатором збірки.

## Реалізовано

- Читання ASPD-4525, контроль статусу/наявності свіжих даних.
- Показ IAS у км/год і м/с, ΔP у Па та температури сенсора.
- Нуль вручну з перевірками стабільності й збереженням у NVS.
- Зона нечутливості ±3 Па тільки для швидкості.
- ST7789, альбомний dashboard, фіксовані статуси, очищення старого тексту.
- Serial 115200: діагностика LCD, I2C scan, періодичні значення, команда `z`.

Немає запису CSV/microSD, touch-керування, налаштування густини через меню
або serial, вимірювання атмосферного тиску, корекції стисливості,
калібрування масштабу, min/max і середньої швидкості за 1 секунду.

## Відомі обмеження

- 20 мс — цільовий інтервал опитування, а не підтверджені сталі 50 Гц.
  Читання та SPI-передача кадру блокують loop; екран оновлюється з умовою
  250 мс. Не обіцяйте 50 Гц логування чи 10 Гц екрану.
- IAS використовує фіксовану густину 1,225 кг/м³ і модуль тиску.
  Це не повна оцінка істинної швидкості/напрямку чи сертифікований еталон.
- Сталий потік під час ZERO може бути помилково прийнятий за offset.
  Зупинений потік забезпечує користувач; алгоритм не може довести його відсутність.
- Відмова ZERO виводиться в serial; UI не має окремого тривалого повідомлення
  про відмову і може повернутися до попереднього `CAL OK`.
- Параметри нуля прив'язані до фізичного датчика. Після заміни потрібне ZERO.
- Фото/підтвердження власника потрібне для оцінки фізичного LCD. Попередня
  помилка ILI9341 показала, що справний serial не гарантує правильного UI.

## Ручні перевірки після змін

| Сценарій | Очікуваний результат |
| --- | --- |
| Збірка | `pio run -e cyd` завершується SUCCESS |
| Старт | serial повідомляє ST7789, rotation=1, 320×240; датчик 0x28 |
| Екран | темний фон, усі три картки, без смуг/обрізання/дзеркальності |
| Перший запуск без NVS | швидкість `--.-`, тиск/температура видимі, ZERO REQUIRED |
| BOOT за відсутності потоку | прогрес ZERO; після 150 свіжих даних CAL OK |
| Завершення/повтор ZERO | слово ZERO нерухоме, немає залишків літер |
| Відключення сенсора | після ~500 мс NO DATA, приховані числові покази |
| Повернення сенсора | SENSOR OK, дані відновлюються, без залишків тексту |
| Тиск у межах ±3 Па | 0,0 м/с; справжній ΔP лишається на картці |
| Тиск поза зоною | швидкість за sqrt(2*abs(ΔP)/1,225), без віднімання 3 Па |
| Перезапуск | прийняте нульове калібрування збережене |
| Нестабільний ZERO / втрата датчика | відмова/тайм-аут у serial; старий нуль збережений |

Не стирайте NVS на платі власника лише заради перевірки першого запуску.
Не позначайте фізичні сценарії як пройдені, якщо виконана лише збірка.

## Пакет передачі

`tools/package.ps1` формує ZIP з каталогом `AIRSPEED/`, списком SHA-256
для кожного включеного файлу й окремою контрольною сумою архіву.
Після створення скрипт повторно читає ZIP і перевіряє вміст за хешами.
Включено весь каталог бібліотеки разом з її ліцензією; встановлені toolchain
і framework завантажуються PlatformIO окремо. Повна flash-копія власника
не є частиною переносного пакета коду.
