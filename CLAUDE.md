This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Мова спілкування з власником — українська. Детальні правила для агентів — в `AGENTS.md`, стан і ручні перевірки — в `docs/PROJECT_STATE.md`; прочитайте їх перед змінами. Фактичний код і `platformio.ini` важливіші за старі пропозиції.

## Що це

Автономний індикатор повітряної швидкості (IAS): ESP32 CYD (екран ST7789) + датчик Matek ASPD-4525 (MS4525DO, ±1 PSI) по I2C. PlatformIO / Arduino C++ (не LVGL, попри назву плати). Сценарій власника: пропелер у каналі, 30–80 м/с.

## Команди

Єдине середовище — `cyd` (espressif32 6.9.0, Arduino 2.0.17). Тестів і лінтера немає.

```
pio run -e cyd                 # збірка (основна перевірка)
pio run -e cyd -t upload       # прошивка — лише якщо це прямо входить у завдання; закрийте serial monitor
pio device monitor             # 115200 бод
python tools/serial_check.py   # обмежене читання COM-порту (може перезапустити ESP32 через DTR/RTS; команд калібрування не шле, потребує pyserial)
powershell -NoProfile -File tools/package.ps1   # ZIP-архів у dist/ + SHA256 і самоперевірка
```

`upload_port`/`monitor_port` у `platformio.ini` — `COM10` (історично, на іншому ПК може бути інакше). На Windows `pio` — це `%USERPROFILE%\.platformio\penv\Scripts\platformio.exe`. Збірка й serial **не підтверджують** правильність зображення на LCD — не заявляйте візуальну перевірку без фото/підтвердження власника.

## Архітектура

Уся прикладна логіка в одному файлі `src/main.cpp` (~260 рядків): `setup()`/`loop()`, `readSensor()` (I2C 0x28, декодування 14-бітного тиску 10–90% шкали, перевірка статус-байтів), `startZero()` (ручне обнулення), `paintScreen()`/`drawScreen()` (малювання через `Canvas` — sprite 16-біт, fallback 8-біт, потім пряме малювання). Стан калібрування зберігається в NVS (`Preferences`, namespace `airspeed`: `zero` float Па, `cal` bool).

Конфігурація екрана й пінів задається **лише через `build_flags` у `platformio.ini`** (`USER_SETUP_LOADED=1`, ST7789, HSPI, BGR, inversion off). `lib/TFT_eSPI-2.5.33/` — vendored стороння бібліотека, не редагуйте її; `.pio/`, `backups/` (приватна копія flash), `dist/`, `vendor/` не пакуються.

Конвеєр вимірювання (порядок важливий): сирий тиск → мінус збережений нуль → EMA (коеф. 0,12) → знак (< −10 Па = REVERSE) → `IAS = sqrt(2·|ΔP|/1,225)`; `|ΔP| ≤ 3 Па` → швидкість 0,0 (сам тиск не обнуляється, поріг не віднімається). Швидкість приховується без калібрування, під час ZERO та за відсутності свіжих даних >500 мс.

## Обмеження, яких легко порушити

- Екран — **ST7789**, не ILI9341 (повернення спричиняє смуги/обрізання). Rotation=1 → 320×240. GPIO22 = SCL, не використовувати для RGB LED; Touch CS33 і SD CS5 лише утримуються HIGH.
- ZERO тільки вручну (BOOT/GPIO0 або serial `z`/`Z`), 150 свіжих вибірок, відмова при розмаху >40 Па або |offset|>500 Па, тайм-аут 10 с; автокалібрування при старті заборонене. Не стирайте NVS на платі власника.
- Фіксовані координати UI (статус x=258,y=10 з очищенням x=240..319,y=4..23; нижній рядок y=216..239, ZERO x=232, деталі x=268,y=225) — не змінюйте вирівнювання, інакше лишаються фрагменти літер.
- Не додавайте SD, touch, Wi-Fi, автокалібрування, LVGL без прямого запиту. Не видавайте IAS за істинну швидкість чи метрологічний еталон; 20 мс — цільовий інтервал, а не підтверджені 50 Гц.
- Не запускайте ZERO віддалено без підтвердженого зупиненого потоку.
